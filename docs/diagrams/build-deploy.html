Pipeline

Argus build and deploy

From a trunk push to a deployed app: CI on main, the owner's Approve, then one workflow per target.

Sources: README.md (Branches, Deploying), AGENTS.md (Governance), .github/workflows/ (ci.yml, release.yml, ecosystem-release.yml, *-deploy*.yml), docs/deploy-branch.md. The promotion card and the work loop that raise the flag are in argus-config's promotion-deploy.html. Release runs beside the deploy workflows, so a failed deploy never hides a release.
